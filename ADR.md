# ADR 002: Adoção de Versionamento Semântico (SemVer)

## Contexto
Política de numeração e publicação de versões para garantir previsibilidade aos usuários, evitando que atualizações quebrem funcionalidades existentes sem aviso prévio.

## Decisão
Adotamos o Versionamento Semântico (SemVer) para gerenciar as versões deste projeto (`MAJOR.MINOR.PATCH`).
